# Specifications

Plain-language documentation of what the 10 Trees system is meant to do. **This wiki is the source of truth** for system behaviour: each page describes the intention behind a part of the application, written for people, and is kept in step with the code as it changes. Pages do not restate mechanics that can be read from the code.

## Field Workflows

- [Grower Enrollment](/Specifications/Grower-Enrollment) — mentors digitally enroll growers at the household, including criteria, commitments, and a finger-drawn signature.
- [Photo Release Consent](/Specifications/Photo-Release-Consent) — capturing photo consent levels linked to an approved enrollment.
- [Garden Location Mapping](/Specifications/Garden-Location-Mapping) — documenting garden sites with GPS, water availability, and existing trees.
- [Garden Assessment](/Specifications/Garden-Assessment) — recurring garden health and tree survival assessments, including home visits.
- [Assessment Photo Storage](/Specifications/Assessment-Photo-Storage) — optional problem photos on assessments: limits, where they are kept, and who can see them.
- [Class Attendance](/Specifications/Class-Attendance) — tracking permaculture training attendance and tree eligibility.

## Program Management

- [Cohort Management](/Specifications/Cohort-Management) — organising growers and mentors into named, village-scoped cohorts.
- [Grower Status Management](/Specifications/Grower-Status-Management) — Active / Inactive / Exited lifecycle and program exit recording.
- [Mentor Management](/Specifications/Mentor-Management) — mentor accounts, village and cohort assignments, and data isolation.
- [Program Reporting](/Specifications/Program-Reporting) — reports and data export for Centre staff and funders.

## Access & Administration

- [Role-Based Data Visibility](/Specifications/Role-Based-Data-Visibility) — what each role can see and do across the platform.
- [User Administration](/Specifications/User-Administration) — user accounts, impersonation, and the platform-vs-programme admin split.
- [Village Data Management](/Specifications/Village-Data-Management) — village-scoped data isolation and filtering.

## Localization
