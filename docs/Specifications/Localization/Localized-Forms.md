# Localized Forms

Mentors fill out forms in their preferred language so they understand all questions clearly.

With the language set to Xitsonga, every form renders its labels, placeholders, options, and messages in Xitsonga; with English selected, everything is in English (e.g. "Grower Name", "Village", "House Number").

## Per-form examples in Xitsonga

- **Application Form** — labels, placeholders, and validation messages all in Xitsonga; "Vito ra Mulimi" for "Grower Name", "Ndawu" for "Village".
- **Mapping Form** — titled "Swa mepe"; "Xiyimo xa le" for "GPS Location".
- **Garden Assessment** — titled "Swilo swa muako"; all tree type options and problem checkboxes in Xitsonga.
- **Release Form** — the consent text in Xitsonga; "Musayino" for "Signature", "Siku" for "Date".

## Yes/No questions

Everywhere a Yes/No question appears, Xitsonga shows **"Ina"** for Yes and **"Ee"** for No.

## Validation and success messages

Messages appear in the selected language, e.g. in Xitsonga:

- "Vito ra mulimi ri laveka" — "Grower name is required"
- "Ndawu yi laveka" — "Village is required"
- "Ngheniso yi hlayisiwe hi ku humelela" — "Enrollment saved successfully"
