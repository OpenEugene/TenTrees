# Home

Documentation wiki for the **10 Trees** system — an Oqtane-based platform supporting a permaculture tree-growing program: grower enrollment, garden assessment, training attendance, cohort management, and reporting, with full English/Xitsonga localization.

## Contents

- [Specifications](/Specifications) — plain-language documentation of system behaviour. **This is the source of truth** for how the system should behave.
- [Plans](/Plans) — implementation plans, debug plans, and browser-based test plans.
- [Project](/Project) — the BDD project plan, meeting notes and transcripts, and original reference documents.
- [How-To Guides](/How-To-Guides) — step-by-step platform instructions for each role.

## History

This wiki replaced the repository's `Specs/` folder of feature files (retired 2026-07-30); the original files remain in git history. The Specifications pages are the plain-language description of what the application is meant to do. They are written for people — centre staff, mentors and future developers — and are kept in step with the code as it changes.
