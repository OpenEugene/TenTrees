# UX: Enrollment dashboard summary cards should be tappable/clickable to filter list

GitHub issue: #78

The four summary cards on the Enrollment List Dashboard (Pending, Approved, Rejected, Total) display counts but are not interactive. Users expect tapping them to filter the list.

## Checklist

- [ ] Pending card filters enrollment list to pending status
- [ ] Approved card filters to approved status
- [ ] Rejected card filters to rejected status
- [ ] Total card displays all enrollments (no filter)
